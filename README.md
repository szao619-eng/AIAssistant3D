
# AI 3D Assistant

Голосовой помощник для Android с 3D-аватаром, wake-словом «сутулый»,
управлением телефоном через службу доступности, планировщиком действий
и обучением через интернет.

## Возможности

- 3D-аватар на OpenGL ES: вращающийся кристалл, меняет цвет при активности
- Wake-слово: помощник слушает постоянно (пока открыт экран приложения),
  команды работают только после слова «сутулый»
- Голосовые команды: домой, назад, недавние, уведомления, громче, тише,
  вай-фай, настройки, открой <приложение>
- Жесты: тап и свайпы по координатам (`тап по координатам 540 1200`)
- Чтение экрана и клики по надписям (`прочитай экран`, `нажми кнопку Поиск`)
- Планировщик цепочек: `открой ютуб потом нажми кнопку поиск потом громче`
- Обучение: `запомни: погода = найди в интернете погода в Москве`
- Поиск в интернете через открытую API Википедии, выученные факты
  кешируются локально и работают офлайн
- Озвучка ответов через TextToSpeech (русский)

## Сборка

1. Откройте папку проекта в Android Studio — IDE создаст Gradle wrapper
   автоматически (wrapper намеренно не включён в репозиторий).
2. Соберите и запустите на устройстве с Android 8.0+.
3. Разрешите доступ к микрофону при первом запуске.
4. Настройки -> Спец. возможности -> «AI 3D Assistant» — включите службу,
   без неё недоступны жесты, чтение экрана и системные действия.

## CI

GitHub Actions собирает debug-APK при каждом push в `main`
(см. `.github/workflows/android.yml`). Артефакт `app-debug` появится
на вкладке Actions после сборки.

## Структура

| Файл | Назначение |
|---|---|
| `MainActivity.kt` | Распознавание речи, wake-слово, TTS, диалог обучения |
| `AssistantView.kt` | 3D-аватар на OpenGL ES |
| `CommandProcessor.kt` | Разбор команд, выученные правила (learned_rules.json) |
| `GestureController.kt` | Тапы и свайпы по координатам |
| `ActionPlanner.kt` | Цепочки действий через «потом» и «затем» |
| `InternetLearner.kt` | Поиск через API Википедии, локальный кеш фактов |
| `ScreenReader.kt` | Чтение текста с экрана и клики по надписям |
| `AssistantAccessibilityService.kt` | Служба доступности: жесты и системные действия |

## Известные ограничения

- Непрерывное прослушивание в фоне для обычных приложений Android
  не разрешает — wake-слово работает, пока открыт экран приложения.
- Тапы по координатам зависят от разрешения экрана устройства;
  удобный способ найти координаты: Настройки -> Для разработчиков ->
  «Показывать координаты касания».
